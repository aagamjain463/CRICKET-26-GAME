## Round 3 Task 4 — shared presentation foundation: foot stabilization + transition continuity

Worktree/4 adds the shared foot-stabilization foundation. The architecture is explicit:
- The solver reads the authored pose, not the already-stabilized skeleton, so it cannot lock a foot permanently and create a false planted state.
- Two-bone IK is used per leg, with the pole target derived from the current knee offset so the authored bend direction is preserved and the knee does not flip.
- Marks are weight-ramped rather than switched, and releases happen on knee reach or by authored lift-off.
- Ground is cached and measured from the mesh reference pose to avoid adding a frame of motion or using a stale world state.

The substantive defect fixed here was a pelvis-compensation sign error: the code was dropping the hips when the mark was above the animated ankle, which is the case that needs nothing, and doing nothing when the mark was below it, the case that can pull the leg straight. The fix is the opposite sign and the debug string now reports live solver state.
